\chapter{Назначение и границы
версии}\label{ux43dux430ux437ux43dux430ux447ux435ux43dux438ux435-ux438-ux433ux440ux430ux43dux438ux446ux44b-ux432ux435ux440ux441ux438ux438}

Руководство для release \nolinkurl{1.0.0}. Основной маршрут:
поверхностные токи BEM → T-матрица → аналитическое усреднение по всем
ориентациям → локальная модель по размеру. Здесь собраны выполненные
исследования сходимости, формы, интерполяции, невязки и сравнения с
MBS-fast. Числа относятся к конкретным сохранённым экспериментам; номер
версии не означает универсальную точность 1\%.

Для нового материала, формы и диапазона размеров отдельно проверяют
сетку, порядок T, точность оператора, решение системы и интерполяцию.
Полная T для ka=40 получена. Полная T для ka=100 и недельное время её
построения этой версией не подтверждены. Ряд новых ускорений остаётся
экспериментальным.

Основной код --- уравнение Мюллера второго рода, BDM1 на острых
частицах, FMM/FFT и смешанная точность с FP64-проверкой. Гладкая сфера
использует P2. Старый PMCHWT/RWG --- отдельный тракт; его эксперимент
\nolinkurl{muller2} не заменяет BDM1-решатель. Историческое руководство
сохранено в \href{docs/legacy_fixed_orientation_manual.md}{архиве
фиксированной ориентации}.

\chapter{Простой интерфейс: метод, частица и тип
расчёта}\label{ux43fux440ux43eux441ux442ux43eux439-ux438ux43dux442ux435ux440ux444ux435ux439ux441-ux43cux435ux442ux43eux434-ux447ux430ux441ux442ux438ux446ux430-ux438-ux442ux438ux43f-ux440ux430ux441ux447ux451ux442ux430}

Новые команды ветки разработки (16 ноября 2026 г.) работают поверх
проверяемых решателей. Старые \nolinkurl{bem run},
\nolinkurl{bem average} и экспертные скрипты сохранены.
\textbf{\nolinkurl{bem average} --- прежнее численное усреднение по
Эйлеровым углам.} Для аналитического усреднения через T используйте
\textbf{\nolinkurl{bem solve --task average}}.

Пошаговый запуск из терминала:

\begin{verbatim}
./bem wizard
\end{verbatim}

Команда задаёт вопросы о методе, форме, размере, материале и типе
результата, печатает повторяемую командную строку и запускает расчёт. В
пакетном режиме:

\begin{verbatim}
# Одна ориентация частицы; решаются обе поляризации.
./bem solve --method muller --task fixed --shape prism \
  --ka 3 --index 1.3116+0.05i --wavelength 0.532 \
  --aspect 1.4285714285714286 --orientation 0 30 0 \
  --out runs/prism_fixed

# Построить и сохранить полную T, затем аналитически усреднить по SO(3).
./bem solve --method muller --task average --shape prism \
  --ka 3 --index 1.3116 --wavelength 0.532 --symmetry auto \
  --out runs/prism_T_average

# Экспериментальный Дирак на CPU; те же физические параметры.
./bem solve --method dirac --task average --shape prism \
  --ka 3 --index 1.3116 --wavelength 0.532 \
  --out runs/dirac_T_average
\end{verbatim}

\nolinkurl{--task tmatrix} сохраняет T без свёртки SO(3).
\nolinkurl{--task fixed} не строит T. \nolinkurl{--task average}
сохраняет и T, и все 16 усреднённых элементов Мюллера.
\nolinkurl{--ntheta 181} задаёт выходные углы рассеяния 0\ldots180°, не
число ориентаций. Только режим \nolinkurl{fixed} принимает
\nolinkurl{--orientation ALPHA BETA GAMMA}.

FMM, FFT, плотное хранение, GMRES и предобуславливатели --- настройки
вычисления выбранного уравнения. Это не дополнительные физические
методы. Прежний RWG-эксперимент \nolinkurl{muller2} не эквивалентен
основному Мюллеру и не предлагается новичку как взаимозаменяемый
вариант.

Для Дирака \nolinkurl{--backend auto} выбирает плотный SIMD-оператор,
если оценка памяти позволяет. Иначе для симметричной призмы выбирается
\nolinkurl{fmm-sector}: точное ближнее взаимодействие, FMM дальнего
поля, локальная ILU и ограниченная глобальная поправка. Для большой
сферы эта секторная реализация пока недоступна: интерфейс сообщает
ограничение до расчёта. Произвольные формы следует считать Мюллером.
Неподдерживаемое сочетание не заменяется другим уравнением без
сообщения.

\section{Физические параметры и
формы}\label{ux444ux438ux437ux438ux447ux435ux441ux43aux438ux435-ux43fux430ux440ux430ux43cux435ux442ux440ux44b-ux438-ux444ux43eux440ux43cux44b}

\nolinkurl{--index 1.3116+0.1i} задаёт относительный показатель при
внешней среде с показателем 1, временной конвенции exp(-iωt) и Im(m)≥0.
Допускается запись с \nolinkurl{j}. \nolinkurl{--wavelength} --- длина
волны в микрометрах. Вместо \nolinkurl{--ka} можно задать
\nolinkurl{--radius} --- радиус равновеликой сферы в микрометрах; два
способа взаимоисключающие. Длина волны и ka определяют физический
размер, но не заменяют показатель преломления при изменении материала.

Для призмы \nolinkurl{--aspect} означает \textbf{высота / ширина между
гранями}. Значение по умолчанию --- 10/7. SciIce Column с параметрами
L/D=10/7, где D измеряется по вершинам, соответствует другому aspect:
\textbf{1.6495721976846451}. Поэтому:

\begin{verbatim}
./bem solve --method muller --task average --shape prism \
  --ka 20 --aspect 1.6495721976846451 --index 1.3116 \
  --wavelength .532 --dry-run
\end{verbatim}

Для форм MBS используйте \nolinkurl{--particle TYPE PARAMETERS...}, для
файла MBS --- \nolinkurl{--particle-file FILE}, для треугольного OBJ ---
\nolinkurl{--obj FILE}. Это альтернативы \nolinkurl{--shape}, не
дополнительные параметры той же команды.

\begin{verbatim}
# Bullet: длина призматической части 2, диаметр по вершинам 1.
./bem solve --method muller --task average --particle 2 2 1 \
  --ka 3 --symmetry auto --out runs/bullet

# Собственная поверхность. ref здесь задаёт дальнейшее измельчение.
./bem solve --method muller --task fixed --obj particle.obj \
  --ka 3 --ref 1 --orientation 10 40 20 --out runs/imported
\end{verbatim}

Все типы и параметры перечислены в
\href{docs/mbs_particle_shapes.md}{формы MBS}. У OBJ проверяются
замкнутость, ориентация граней и геометрическая симметрия. Положение
осей в файле важно для применимости специальных C6-сокращений. Для
импортированных сеток автоматический ref --- оценка по самому длинному
ребру, а не проверка качества сетки.

\section{Ориентация и
симметрия}\label{ux43eux440ux438ux435ux43dux442ux430ux446ux438ux44f-ux438-ux441ux438ux43cux43cux435ux442ux440ux438ux44f}

Лабораторная падающая волна распространяется вдоль +z, две поляризации
--- по x и y. Наблюдение идёт в плоскости xz. Углы задают активное
вращение тела в лабораторную систему: R=Rz(alpha) Ry(beta) Rz(gamma), в
градусах. Для расчёта в системе тела и падающие поля, и направления
наблюдения, и базисы поляризации преобразуются одной матрицей. Нельзя
повернуть только направление падения и оставить старый базис выходного
поля.

\nolinkurl{--symmetry auto} проверяет доступные геометрические операции
и выбирает совместимые сокращения. \nolinkurl{--symmetry none} отключает
сокращения. Явные \nolinkurl{c6}, \nolinkurl{c6v}, \nolinkurl{d6h}
требуют соответствующей геометрии относительно осей тела: C6 ---
вращения вокруг z; C6v добавляет вертикальные зеркала; D6h также
горизонтальное зеркало. Например, bullet имеет C6v, но не D6h: ошибочная
декларация отвергается. Геометрическая группа не отменяет численных
проверок оператора, упаковки и восстановленных столбцов.

Общий детектор находит и другие конечные группы. Мюллер использует
реализованные совместимые преобразования, в том числе C2. Интерфейс не
обещает ускорение для каждой найденной операции O(3). Дирак сейчас имеет
секторные реализации C6/C6v/D6h для призмы; для фиксированного общего
падения используются полные векторы, а не ошибочное присвоение падающей
плоской волне одного сферического сектора.

\section{Что выбирается
автоматически}\label{ux447ux442ux43e-ux432ux44bux431ux438ux440ux430ux435ux442ux441ux44f-ux430ux432ux442ux43eux43cux430ux442ux438ux447ux435ux441ux43aux438}

\begin{itemize}
\tightlist
\item
  Начальный ref из ka, \textbar m\textbar, геометрического размера рёбер
  и порядка базиса. Числа ref в Дираке и Мюллере \textbf{не означают
  одинаковую сетку}.
\item
  Начальный L из радиуса описанной сферы: kR+4(kR)\^{}(1/3)+2 с
  округлением вверх и дополнительным запасом для более строгого запроса.
\item
  Невязка: обычно 1e-5 для Мюллера и 1e-8 для Дирака; при ka≤1
  применяется 1e-8, поскольку слабые высшие моды чувствительны к
  численной компенсации.
\item
  Для Дирака --- способ хранения оператора, размер пакета,
  последовательное освобождение секторных факторов, ограничение
  глобального пространства.
\item
  Число потоков, резерв ОЗУ и диска; операционные бюджеты записываются в
  план.
\end{itemize}

\nolinkurl{--accuracy-percent 1} --- целевая точность \textbf{начального
подбора}, не обещание автоматически доказанной ошибки 1\%. В
\nolinkurl{result_summary.json} честно записано
\nolinkurl{accuracy_certified: false}. Текущий простой запуск не
выполняет скрытую серию полных расчётов ref+1 и L+2. Для физической
сертификации нужны эти независимые сравнения по всем требуемым углам и
элементам. Невязка системы, ошибка сетки и усечение T --- разные ошибки.

Эксперт может задать \nolinkurl{--ref}, \nolinkurl{--L},
\nolinkurl{--tol}. Для Дирака также доступны
\nolinkurl{--backend dense|fmm-sector}, \nolinkurl{--batch-size},
\nolinkurl{--global-patches}. Последнее ограничивает число глобальных
P1-участков предобуславливателя и \textbf{не является L}. При нехватке
памяти программа не уменьшает незаметно ref или L.

\section{План, файлы,
продолжение}\label{ux43fux43bux430ux43d-ux444ux430ux439ux43bux44b-ux43fux440ux43eux434ux43eux43bux436ux435ux43dux438ux435}

\begin{verbatim}
# Показать параметры и точную команду, без сборки и расчёта.
./bem solve --method dirac --task average --ka 20 --ram-gib 40 --dry-run

# Возобновить по сохранённой конфигурации и проверенным столбцам.
./bem continue runs/dirac_T_average
\end{verbatim}

Нужные библиотеки собираются при отсутствии; \nolinkurl{--no-build}
запрещает такую сборку. Для CPU Дирака нужны g++, NumPy, SciPy, psutil,
BLAS/LAPACK; секторный FMM использует FMM3D с зафиксированным commit
\nolinkurl{cad293ae9b8ae1218dd8319d459ffcc5f1412875}. При первом запуске
FMM он загружается и собирается локально. SO(3) требует gfortran и
\nolinkurl{bin/tmatrix_so3_mstm}. GPU-методы требуют CUDA. Расширенные
команды сборки даны далее. \nolinkurl{./bem methods} и справка не
загружают нативные библиотеки.

Старый PMCHWT сохраняет свой \nolinkurl{result/result.json}. Матрицы
Мюллера новых fixed/T-режимов безразмерны: для дифференциального сечения
умножать на (lambda/(2*pi))². Файлы фиксированного падения не содержат
T. \nolinkurl{solution.npz} Дирака дополнительно сохраняет прежний
совместимый формат. Для огромных T лучше читать \nolinkurl{tmatrix.npy}
с \nolinkurl{numpy.load(..., mmap_mode='r')}.

Если расчёт уже завершён и файлы результата существуют,
\nolinkurl{bem continue} сообщает об этом без повторного решения и без
повторной проверки всех столбцов. Совместимость незавершённых чекпоинтов
проверяет сам решатель: другая геометрия, материал, численные параметры
или вычислительный код не принимаются как та же задача. Перенос
checkpoint между версиями требует отдельной проверки. Фиксированная
ориентация при повторном запуске может пересчитываться целиком;
гарантированная гранулярность продолжения T --- принятый столбец/пакет.

\chapter{Физические параметры и одинаковая
геометрия}\label{ux444ux438ux437ux438ux447ux435ux441ux43aux438ux435-ux43fux430ux440ux430ux43cux435ux442ux440ux44b-ux438-ux43eux434ux438ux43dux430ux43aux43eux432ux430ux44f-ux433ux435ux43eux43cux435ux442ux440ux438ux44f}

Размер задаётся через радиус равновеликой сферы \(a\):

\[ka=k_0a,\qquad k_0=2\pi/\lambda,\qquad a=ka\lambda/(2\pi).\]

Внутри задачи геометрия нормирована на \(a=1\). Длина волны в
микрометрах задаёт перевод в физические единицы. При дисперсии изменение
длины волны требует также изменения показателя преломления; это уже
другая семья T. Используется временная зависимость \(\exp(-i\omega t)\)
и пассивное поглощение \(m=n+i\kappa\), \(\kappa\geq0\).

Для правильной шестиугольной призмы \nolinkurl{prism-aspect} ---
отношение высоты \(H\) к ширине между противоположными \textbf{гранями}
\(D_f\), не к диаметру по вершинам. Пусть \(\eta=H/D_f\). Тогда

\[V=\frac{\sqrt3}{2}D_f^2H,\quad
\frac{D_f}{a}=\left(\frac{8\pi}{3\sqrt3\eta}\right)^{1/3},\quad
\frac{R}{a}=\frac{D_f}{a}\sqrt{\frac13+\frac{\eta^2}{4}},\]

где \(R\) --- радиус описанной сферы. Он существенно влияет на
необходимый \(L\). Диаметр по вершинам \(D_v=2D_f/\sqrt3\); поэтому
\(H/D_v=\eta\sqrt3/2\).

Текущий столбик: \(m=1.3116\), \(\lambda=0.532\) мкм,
\(H/D_f=1/0.7=10/7\). Для него \(R/a\approx1.379127\), а параметр MBS по
диаметру вершин равен \(H/D_v\approx1.2371791483\). При ka=40 радиус
равновеликой сферы около 3.387 мкм. Старые мультиразмерные данные
ka=10\ldots12 имеют \textbf{\(H/D_f=1\)}; их нельзя смешивать с этим
столбиком.

\section{Аналитическое
усреднение}\label{ux430ux43dux430ux43bux438ux442ux438ux447ux435ux441ux43aux43eux435-ux443ux441ux440ux435ux434ux43dux435ux43dux438ux435}

\nolinkurl{tmatrix_so3_mstm.py} свёртывает произведения элементов T с
угловыми коэффициентами и вычисляет усреднённую матрицу Мюллера.
Интегрирование по SO(3) аналитическое:
\nolinkurl{Euler_quadrature_nodes = 0}. Сетка \nolinkurl{ntheta} задаёт
\textbf{угол рассеяния выходного графика}, а не ориентации частицы.

Угловая сетка проекции дальнего поля при построении T --- другая
численная операция. Её сходимость проверяется отдельно. Аналитическое
усреднение устраняет ошибку ориентационной квадратуры, но сохраняет
ошибки самой T.

В принятой нормировке безразмерных токов и сферических волн:

\[C_{sca}=\frac{2\pi}{(ka)^2}\|T\|_F^2,\qquad
C_{ext}=-\frac{2\pi}{(ka)^2}\operatorname{Re}\operatorname{tr}T.\]

Для физических сечений в мкм² результат умножается на \(a^2\). Сравнивая
матрицы Мюллера, проверяйте Stokes-конвенцию и единицы; дополнительная
подгонка масштаба по переднему пику недопустима.

\section{Вращения и
зеркала}\label{ux432ux440ux430ux449ux435ux43dux438ux44f-ux438-ux437ux435ux440ux43aux430ux43bux430}

Для правильной центрированной призмы используется C6 и зеркальная
симметрия: горизонтальное отражение, вертикальные отражения и связанные
сектора D6h. \nolinkurl{c6-pack} кодирует допустимые моды в фазовые
правые части, \nolinkurl{mirror-pack} использует горизонтальную
чётность. \nolinkurl{vertical-preconditioner} согласует обратный
предобуславливатель с вертикальными отражениями. Полярные и аксиальные
компоненты токов при отражении имеют разные знаки.

Проверяется действие оператора, упаковка/распаковка, дальнее поле и
полная невязка. Невязка закодированной правой части не является
отдельным измерением невязки каждого восстановленного столбца. В отчётах
ka=40 это различие сохранено. Для OBJ без точной симметрии упаковка
неприменима.

\chapter{Как проверяется точность
1\%}\label{ux43aux430ux43a-ux43fux440ux43eux432ux435ux440ux44fux435ux442ux441ux44f-ux442ux43eux447ux43dux43eux441ux442ux44c-1}

Основная опубликованная угловая метрика:

\[\epsilon_M=\max_{\theta,i,j}
\frac{|M_{ij}^{test}(\theta)-M_{ij}^{ref}(\theta)|}{M_{11}^{ref}(\theta)}.\]

Она охватывает все 16 элементов на указанной сетке углов и использует
одну физически понятную нормировку. Это \textbf{не} относительная ошибка
каждого малого \(M_{ij}\). Вблизи его нуля такая относительная ошибка
неустойчива; на слабых элементах она может превышать 1\% при выполнении
критерия выше. Сечения \(C_{sca}\) и \(C_{ext}\) сравниваются отдельно
относительно эталона.

Пять независимых проверок:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Сетка: сравнение \nolinkurl{ref} и \nolinkurl{ref+1} при достаточном
  L.
\item
  Порядок: последовательные усечения T, затем контроль большего
  эталонного L.
\item
  Оператор: квадратура, Duffy, ближняя зона, FMM/FFT и FP64.
\item
  Решение: истинная невязка и устойчивость конечных элементов Мюллера.
\item
  Мультиразмер: новые прямые T в точках, не использованных для обучения.
\end{enumerate}

Каждая проверка с допуском 1\% по отдельности не даёт суммарный бюджет
1\%. Для итоговой цели нужен запас и прямой контроль конечного
результата. Сравнение на дискретных углах также не является строгой
оценкой между ними.

\chapter{Мультиразмерная T: где возникает
экономия}\label{ux43cux443ux43bux44cux442ux438ux440ux430ux437ux43cux435ux440ux43dux430ux44f-t-ux433ux434ux435-ux432ux43eux437ux43dux438ux43aux430ux435ux442-ux44dux43aux43eux43dux43eux43cux438ux44f}

При фиксированной форме и материале геометрические структуры и кэши
можно переиспользовать, но оператор зависит от ka. Одна T при ka=40 не
определяет T соседних размеров без дополнительной информации о частотной
зависимости.

Проверенный маршрут: несколько прямых опорных T → рациональная модель
элементов T → независимые прямые контрольные размеры → аналитическое
SO(3) для плотной сетки. Интерполируется \textbf{комплексная T}, затем
вычисляются квадратичные величины; интерполяция одной M11 не
восстанавливает полную T.

Обязательны одинаковые геометрия, материал, базис, порядок, проекция и
соглашения. Обучающие и контрольные размеры не пересекаются. При провале
интервал сужается или добавляются опоры. Экстраполяция вне проверенного
интервала запрещена политикой локальной модели.

Для другой собственной семьи можно использовать API. Ниже предполагаются
\textbf{заранее завершённые} девять опор и отдельная контрольная T,
сохранённые по указанной схеме имён. В release эти большие файлы не
вложены.

\begin{verbatim}
import json
import sys
from pathlib import Path
import numpy as np
sys.path.insert(0, "scripts")
from tmatrix_size_interpolation import fit_aaa, validate_family
from tmatrix_so3_mstm import analytic_mueller_tmatrix

base = Path("runs/family")
nodes = np.linspace(10, 12, 9)
folders = [base / f"ka{x:.3f}" for x in nodes]
reports = [json.loads((p / "summary.json").read_text()) for p in folders]
assert all(r["complete"] for r in reports)
validate_family([r["parameters"] for r in reports])
samples = [np.load(p / "tmatrix.npy", mmap_mode="r") for p in folders]
model, diagnostics = fit_aaa(nodes, samples, tolerance=1e-6)

# Эта точка не входит в обучение; прямой контроль считается отдельно.
x = 10.125
control = base / f"ka{x:.3f}"
report = json.loads((control / "summary.json").read_text())
assert report["complete"]
validate_family([reports[0]["parameters"], report["parameters"]])
truth = np.load(control / "tmatrix.npy", mmap_mode="r")
predicted = model.evaluate(x)
L = reports[0]["parameters"]["order"]
theta = np.linspace(0, 180, 1801)
kwargs = dict(precision="fp64", threads=2, cyclic_order=6)
reference, _ = analytic_mueller_tmatrix(truth, L, theta, **kwargs)
candidate, _ = analytic_mueller_tmatrix(predicted, L, theta, **kwargs)
error = np.max(np.abs(candidate-reference) / reference[:, 0, 0, None, None])
print("All16 / M11 error, %:", 100*error)
\end{verbatim}

\nolinkurl{training_tolerance_met} в \nolinkurl{diagnostics} относится
только к обучающим T. Перед выпуском плотной сетки нужны
\textbf{несколько} исключённых контрольных размеров, проверки сечений и
поверхности. \nolinkurl{cyclic_order=6} допустим только при проверенной
C6-симметрии. Для произвольной формы используют 1. Оценка в новых точках
использует барицентрические коэффициенты по размеру; она не переносит
токи между новыми узлами поверхностной сетки.

\chapter{Сравнение BEM и MBS-fast при
ka=40}\label{ux441ux440ux430ux432ux43dux435ux43dux438ux435-bem-ux438-mbs-fast-ux43fux440ux438-ka40}

Использована завершённая BEM T выше с аналитическим SO(3). MBS-fast:
\(m=1.3116\), та же длина волны и объём, \(H/D_v=1.2371791483\). Новый
бинарник со surface/shadow изменениями сравнивался в когерентном и
некогерентном режимах. В переносимом наборе записаны commit и SHA256
бинарника.

Условия нового MBS: 8 независимых Haar/Owen--Sobol перемешиваний по 4096
ориентаций, 32 азимутальных отсчёта, глубина 14, 222 угла рассеяния. Это
\textbf{фиксированный объём выборки}, не новый успешно сошедшийся
fullauto на 1\% или 4\%. Старые fullauto-запуски имеют свои отдельные
статусы.

Общая величина --- \(k^2\,d\sigma/d\Omega\). В сравнении использован
физический масштаб 139.4878795 и перевод Stokes через диагональ
\((1,1,-1,-1)\); подгонки амплитуды под BEM нет. 95\%-интервалы ---
поточечные, не совместная гарантия всех углов/элементов. Они
характеризуют статистику MBS, не точность его физической модели.
